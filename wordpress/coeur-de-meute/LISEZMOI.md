# Thème WordPress « Coeur de Meute »

Thème sur mesure qui reproduit à l'identique le site Coeur de Meute, avec tous les contenus modifiables depuis WordPress.

## Installation

1. Chez votre hébergeur, installez WordPress (la plupart proposent une installation « en un clic »).
2. Dans WordPress : **Apparence → Thèmes → Ajouter → Téléverser un thème**, choisissez `coeur-de-meute.zip`, puis **Activer**.
3. C'est tout : à l'activation, le thème crée automatiquement les pages, les 7 services, l'équipe, la FAQ, la galerie et le menu.

## Où modifier quoi ?

| Je veux modifier… | Où ? |
| --- | --- |
| Téléphone, e-mail, adresse, horaires, textes de l'accueil, valeurs, bas de page | **Apparence → Personnaliser → Contenus Coeur de Meute** |
| Les prix du simulateur de la pension | **Tarifs pension** |
| Un service (textes, liste, étapes, icône, couleur, mise en avant) | **Services** |
| Ajouter un service | **Services → Ajouter un service** (il apparaît automatiquement dans le menu et sur l'accueil) |
| L'ordre des services | Champ **Ordre** à droite de chaque service (0 = premier) |
| L'équipe (page Qui sommes-nous) | **Équipe** (une photo peut être ajoutée via « Image mise en avant ») |
| Les questions fréquentes (page À propos) | **FAQ** |
| Les photos de la galerie | **Pages → Galerie** : ajoutez des images dans le bloc « Galerie » |
| La présentation d'Elodie (page Qui sommes-nous) | **Pages → Qui sommes-nous ?** (texte) + « Image mise en avant » (photo) |
| Le menu | **Apparence → Menus** |

### Astuces

- Dans les champs « une ligne par info », séparez le titre et le texte par une barre verticale : `Pour qui ? | Chiens et chats`.
- « Mettre en avant » affiche le service en grande carte « Notre coeur de métier » (éducation et pension).
- Si l'élément « Nos services » du menu n'a pas de sous-éléments, la liste des services s'affiche automatiquement en sous-menu.
