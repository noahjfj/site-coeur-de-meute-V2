Enregistrer sur le site

Première utilisation : connecter votre compte GitHub (à faire une seule fois)
  1. Connectez-vous sur github.com, puis ouvrez cette page de création de clé.
  2. Nom de la clé : « Tarifs Coeur de Meute ». Expiration : choisissez une longue durée (par exemple 1 an).
  3. « Repository access » : choisissez Only select repositories puis le dépôt site-coeur-de-meute-V2.
  4. « Permissions » → « Repository permissions » → Contents : Read and write.
  5. Cliquez sur « Generate token », copiez la clé (elle commence par github_pat_) et collez-la ci-dessous.

La clé reste uniquement dans votre navigateur. Elle permet seulement de modifier ce site.

Pas de clé ? Méthode manuelle
  1. Cliquez sur « Copier le fichier des tarifs ».
  2. Ouvrez le fichier des tarifs sur GitHub.
  3. Effacez tout son contenu, collez le nouveau, puis cliquez sur « Commit changes ».
